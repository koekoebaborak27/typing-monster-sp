# 結果画面の表示

評価の基準は [結果の評価](../../01_requirements/battle/02_結果の評価.md)、ボス図鑑の表示は [ボスデータと選び方](../boss-zukan/01_ボスデータと選び方.md#枠ランクの判定)。`BattleSession`（画面間でバトルの内容を受け渡すメモリ）は [画面間で受け渡すもの](../common/01_URLと画面遷移.md#画面間で受け渡すもの)。画面の見た目は [screens.html](../../mock/screens.html) と [DESIGN.md](../../../../DESIGN.md)。

## 結果の作り方

バトルが「とどめの一撃」になったとき（[状態の遷移](01_バトル画面の状態遷移.md#状態の遷移)）、結果画面へ移る前に次の順で行う。

1. 撃破の記録を保存する。ボスの撃破回数を +1、`life` が 3 なら `perfectCount` を +1（[保存のタイミング](../local-storage/01_保存データの形.md#保存のタイミング)）。
2. 次の値を `BattleSession` に置く。

| 項目 | 内容 |
| --- | --- |
| `mode` / `level` | 「もう1回」で同じ条件にするため |
| `boss` | 倒したボス |
| `life` | 残りライフ（評価の基準） |
| `killCountBefore` / `killCountAfter` | 撃破回数（更新の前と後） |
| `perfectCount` | パーフェクト勝利の更新後の回数 |
| `reviewList` | ふりかえりに出す問題 |
| `revengeCleared` | リベンジモードで、更新後の「まちがえた問題」が5問未満になったか（通常モードは常に `false`） |

## 表示の出し分け

| 表示 | 条件 | 内容 |
| --- | --- | --- |
| ボス | 常に | 丸の中の絵文字（怒りモードにはしない） |
| 評価 | `life` が 3 | パーフェクト勝利！ ★★★ |
| | `life` が 2 | 勝利！ ★★☆ |
| | `life` が 1 | 勝利！ ★☆☆ |
| | `life` が 0 | ギリギリ勝利！（★の行は出さない） |
| 撃破回数 | 常に | 「◯◯をたおした（`killCountAfter`回目）」（◯◯はボス名） |
| お知らせ帯（図鑑） | `killCountBefore` が 0 | NEW！ボス図鑑に登録された！ |
| | ランクが上がった | ランクアップ！ 枠が銀になった（金のときは「枠が金になった」） |
| お知らせ帯（パーフェクト） | `life` が 3 | パーフェクト勝利 `perfectCount`回目！ |
| ふりかえり | `reviewList` が1問以上 | 「ふりかえり（まちがえた問題）」の見出しと、問題ごとに 問題文・「正解：正解の選択肢の文」・解説 |
| | `reviewList` が空 | まちがいなし！ |
| 「もう1回」 | `revengeCleared` が `false` | 同じ `mode`・`level` で次のバトルを始める（先読み済みの問題を使う） |
| | `revengeCleared` が `true` | ボタンの代わりに「ぜんぶリベンジした！」と表示する |
| 「ホームへ」 | 常に | `/` へ移る |

- お知らせ帯は条件に当てはまるものをすべて、図鑑 → パーフェクトの順に縦に並べる。何も当てはまらなければ出さない。
- 「もう1回」を押したとき、先読みが済んでいなければ [エラーと特殊表示](../common/02_エラーと特殊表示.md#一覧) に従う。
- 結果画面を開いたら、[先読み](../question-api/01_出題の選び方.md#先読み) を始める。
