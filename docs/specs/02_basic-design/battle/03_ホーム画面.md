# ホーム画面の動作

画面の項目は [概要と対象範囲](../../01_requirements/common/01_概要と対象範囲.md#画面一覧4画面)、見た目は [screens.html](../../mock/screens.html)。ここでは、表示の出し分けと操作だけを決める。

## 読み込み

- ホームを開いたとき、[保存データ](../local-storage/01_保存データの形.md#読み込み) を読み込む。読み込むまでは、リベンジモードを鍵（押せない）にして、図鑑の収集率は表示しない。
- 保存できないと判明したときは、画面の上部に [エラーと特殊表示](../common/02_エラーと特殊表示.md#一覧) の帯を出す。

## 表示の出し分け

| 表示 | 条件 | 内容 |
| --- | --- | --- |
| サウンド | 常に | 「🔊 音 ON」／「🔇 音 OFF」。タップで切り替え、すぐ保存する |
| リベンジモード（未開放） | `wrongIds` が5問未満 | 鍵マーク付きで押せない。「まちがえた問題が5問たまると遊べるよ（いま N問）」（N は `wrongIds` の数） |
| リベンジモード（開放） | `wrongIds` が5問以上 | 押せる。「リベンジモード」の下に「まちがえた問題 N問」 |
| ボス図鑑 | 常に | 「📖 ボス図鑑　X / 20」（X は撃破済みのボスの数） |

## 操作

| 操作 | 動作 |
| --- | --- |
| かんたん／ふつう／むずかしい | サウンドを有効にし、`mode` = 通常、`level` = 1／2／3 を `BattleSession` に置き、`/battle` へ移る |
| リベンジモード（開放時） | サウンドを有効にし、`mode` = リベンジを置いて `/battle` へ移る |
| ボス図鑑 | `/zukan` へ移る |

- サウンドの有効化は、ブラウザの制限（タップ前は音を鳴らせない）のため、必ずこのタップの中で行う。
