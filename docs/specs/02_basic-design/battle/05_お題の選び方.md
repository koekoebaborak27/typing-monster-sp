# お題の選び方

要件は [お題の出し方](../../01_requirements/battle/03_お題の出し方.md)・[言葉のデータ](../../01_requirements/question-data/01_言葉のデータ.md)。ここでは、1バトルの5語を選ぶ手順と、最近出た言葉の記録を決める。実装は `word` モジュールの `pick-words.ts`。

## 言葉の形

言葉1つは `{ id: string; text: string }` とする（型は `word/types.ts` の `Word`）。`text` はお題として表示する、ひらがなの文字列。

- 一覧は `word/data/words.ts` に、`WORDS`（`Word` の配列）として置く。`word` モジュールの外へは出さない。
- IDは `w-001` の形の連番（3けた、0で埋める）とする。言葉を足すときは、いちばん大きい番号の次を使う。消した言葉の番号は使い回さない。並べ替えても、字を直しても、IDは変えない。

## 言葉を選ぶ基準

| 項目 | 基準 |
| --- | --- |
| 文字数 | 3〜6文字。小さい文字と「ー」も1文字と数える |
| 品詞 | 名詞だけ |
| 使ってよい文字 | ふつうの文字（「を」を除く）、濁点・半濁点が付く文字（「ぢ」「づ」を除く）、小さい「っ」「ゃ」「ゅ」「ょ」、のばす音「ー」 |
| 使わない文字 | 「を」「ぢ」「づ」「ゔ」、小さい「ぁ」「ぃ」「ぅ」「ぇ」「ぉ」「ゎ」 |
| 言葉の中身 | 小学校高学年が知っている言葉。人を傷つける言葉・こわい言葉・商品名・人の名前は入れない |
| 分野 | データには持たない。生き物・食べ物・学校・自然・くらし・行事などから、かたよらないように選ぶ |

- 「づ」を入れないのは、「ず」との書き分けで間違えるのを避けるため（打ち方の練習にしたい）。
- 「ー」を含む言葉は、ふつうはカタカナで書く言葉をひらがなで書いたもの（らーめん、さっかー など）。
- 「ん」のあとに、あ行・な行・や行が続く言葉（ほんや、きんようび）も入れる。パソコンのローマ字入力では n を2回打たないと別の文字になり、ミスになる。
- 文字数ごとの数の目安は、3文字30語・4文字40語・5文字20語・6文字10語。
- 文字数・使ってよい文字・IDの形・重複は、`word/data/words.test.ts` で確かめる。

## 選ぶ手順

バトルを始めるたびに、端末で次の順に選ぶ。乱数は引数で受け取る（単体テストで結果を固定できるようにするため）。

1. **候補を作る。** 言葉の一覧から、保存データの `recentIds`（最近出た言葉のID）に含まれるものを除く。
2. **5語を選ぶ。** 候補から、等しい確率でランダムに、重複しない5語を選ぶ。選んだ順を出す順にする（1〜3番目が通常問題、4〜5番目がとどめ問題。選び方に違いは無い）。
3. **候補が5語に満たないとき**は、候補をすべて使い、足りない分を `recentIds` に含まれる言葉からランダムに選ぶ（言葉の数を減らしたときなどのための備え。約100語あれば起こらない）。

- `recentIds` に、言葉の一覧に無いIDがあっても無視する。
- 「もう1回」でも、同じ手順で選び直す。

## 最近出た言葉の記録

- バトルの開始時に、選んだ5語のIDを `recentIds` の末尾へ加え、新しい20件だけ残す。保存は、ボスの記録と一緒に1回で行う（[保存のタイミング](../local-storage/01_保存データの形.md#保存のタイミング)）。
- 開始時に保存するので、途中で離れたバトルの言葉も「最近出た」として数える（ボスと同じ扱い）。
