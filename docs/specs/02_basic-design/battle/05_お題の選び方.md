# お題の選び方

要件は [お題の出し方](../../01_requirements/battle/03_お題の出し方.md)・[言葉のデータ](../../01_requirements/question-data/01_言葉のデータ.md)。ここでは、1バトルの5語を選ぶ手順と、最近出た言葉の記録を決める。実装は `word` モジュールの `pick-words.ts`。

言葉を選ぶ基準（文字数など）と、言葉のデータを置くファイルは、まだ決めていない（言葉を作るときに決める）。

## 言葉の形

言葉1つは `{ id: string; text: string }` とする。`text` はお題として表示する、ひらがなの文字列。

## 選ぶ手順

バトルを始めるたびに、端末で次の順に選ぶ。乱数は引数で受け取る（単体テストで結果を固定できるようにするため）。

1. **候補を作る。** 言葉の一覧から、保存データの `recentIds`（最近出た言葉のID）に含まれるものを除く。
2. **5語を選ぶ。** 候補から、等しい確率でランダムに、重複しない5語を選ぶ。選んだ順を出す順にする（1〜3番目が通常問題、4〜5番目がとどめ問題。選び方に違いは無い）。
3. **候補が5語に満たないとき**は、候補をすべて使い、足りない分を `recentIds` に含まれる言葉からランダムに選ぶ（言葉の数を減らしたときなどのための備え。約100語あれば起こらない）。

- `recentIds` に、言葉の一覧に無いIDがあっても無視する。
- 「もう1回」でも、同じ手順で選び直す。

## 最近出た言葉の記録

- バトルの開始時に、選んだ5語のIDを `recentIds` の末尾へ加え、新しい20件だけ残す。保存は、ボスの記録と一緒に1回で行う（[保存のタイミング](../local-storage/01_保存データの形.md#保存のタイミング)）。
- 開始時に保存するので、途中で離れたバトルの言葉も「最近出た」として数える（ボスと同じ扱い）。
