## 画面イメージからの変更点

- 上部の表示は「4 / 5問」のみとし、Stage は表示しない。
- HPは500とし、HPバーは比率で表示する。
- ボスは丸い背景の中に絵文字を表示する。怒りモードでは丸を赤くする。
- ボス名は固有名とし、怒りモードでは「いかりの◯◯」とする。
- HPバーの下に、何問目かを示す進み具合のバーを表示する。
- 選択肢には A / B / C のラベルを付ける。とどめ問題の出し直しでは中身だけ並べ替え、ラベルの位置は固定する。
- 配色は画面イメージのダーク配色をもとに [DESIGN.md](../../../../DESIGN.md) へ反映済み。
- 画面イメージに無い要素（不正解時の解説と「わかった」ボタン、怒りモードの吹き出しと💢、とどめの一撃の数字）の配置は、[mock/screens.html](../../mock/screens.html) と [DESIGN.md](../../../../DESIGN.md) で決める。
- 画面イメージに無かった表示を追加した：とどめ問題の出し直し時の「もういちど こたえてね」、ボス図鑑の「パーフェクト勝利 N回」。[mock/screens.html](../../mock/screens.html) に反映済み。
