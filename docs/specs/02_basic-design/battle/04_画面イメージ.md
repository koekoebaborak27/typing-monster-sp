- 全画面：[mock/screens.html](../../mock/screens.html)

配色・部品・配置の決まりごとは [DESIGN.md](../../../../DESIGN.md) に従う。配置と見た目は、画面イメージのとおりに作る（画面イメージから変える点は無い）。

## 画面イメージに無いが、表示するもの

画面イメージは代表的な場面だけを描いている。次の表示は絵に無いが、基本設計で決めている。

| 表示 | 決めている場所 |
| --- | --- |
| 1〜4問目を打ち終えたときの「100ダメージ！」（とどめの一撃と同じ場所に、「とどめの一撃！」を付けずに出す） | [バトル画面の状態遷移](01_バトル画面の状態遷移.md#表示の出し分け) |
| 日本語入力がオフのときの「にほんご入力を オンにしてね」（ミスを知らせる文と同じ場所に出す） | [バトル画面の状態遷移](01_バトル画面の状態遷移.md#表示の出し分け) |
| 結果画面の「NEW！ボス図鑑に登録された！」「パーフェクト勝利 N回目！」（「ランクアップ！」と同じ帯で出す） | [結果画面の表示](02_結果画面の表示.md#表示の出し分け) |
| 結果画面の★3・★なしのときの表示 | [結果画面の表示](02_結果画面の表示.md#表示の出し分け) |
| ホームの「きろくをほぞんできないよ。あそぶことはできるよ。」の帯 | [エラーと特殊表示](../common/02_エラーと特殊表示.md#一覧) |

## 画面イメージの数字の読み方

- 進み具合バーの幅は「打ち終えた問題の数 / 5」（2問目を打っている間は 20%）。
- バトル画面の絵にあるキーボードは、端末の標準のキーボードを表したもので、アプリでは描かない。
