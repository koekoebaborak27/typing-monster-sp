# 保存データの形

要件は [端末内の保存](../../01_requirements/local-storage/01_端末内の保存.md)。実装は `progress` モジュール（`schema.ts` が形の検証、`storage.ts` が読み書き）。

## 保存先

localStorage の1つのキー `typing-monster-sp` に、次の JSON を文字列で保存する（項目をまたいで同時に更新でき、途中まで書かれた状態にならないため、キーは分けない）。

```json
{
  "version": 1,
  "recentIds": ["w-012", "w-047"],
  "lastBossId": "misstouch-oni",
  "bossKills": { "misstouch-oni": 5, "renda-dako": 3 },
  "perfectCount": 2,
  "soundOn": true
}
```

| 項目 | 型 | 初期値 | 内容 |
| --- | --- | --- | --- |
| `version` | 整数 | `1` | 保存データの形のバージョン |
| `recentIds` | 文字列の配列 | `[]` | 最近出た言葉のID。古い順で、最大20件 |
| `lastBossId` | 文字列または `null` | `null` | 直前のバトルのボスID。ボスの一覧に無いIDも保存データとしてはそのまま読み込み、`null` と同じに扱うのは `boss` モジュール（[ボスの選び方](../boss-zukan/01_ボスデータと選び方.md#ボスの選び方)） |
| `bossKills` | `{ ボスID: 整数 }` | `{}` | ボスごとの撃破回数。1回以上のボスだけ持つ。ボスの一覧に無いIDも捨てずに持つ（一覧の変更で記録を消さないため。図鑑では無視する） |
| `perfectCount` | 整数 | `0` | パーフェクト勝利（ミス0回で勝ったバトル）の回数 |
| `soundOn` | 真偽値 | `true` | サウンドON/OFF |

- ボスIDは [ボスデータと選び方](../boss-zukan/01_ボスデータと選び方.md#ボス一覧) のID。
- 上の例の言葉のID（`w-012`）は仮のもの。IDの付け方は、言葉を作るときに決める。
- ミスした言葉・ミスの回数・打つ速さ・最高評価は保存しない。

## 保存のタイミング

| タイミング | 保存する項目 |
| --- | --- |
| バトルの開始（ボスと5語を選んだ直後） | `lastBossId`（選んだボスのID）と `recentIds`（選んだ5語のIDを末尾へ加え、新しい20件だけ残す）を、1回で保存する |
| とどめの一撃で勝利が決まったとき（結果画面へ移る前） | `bossKills`、`perfectCount`（ミスが0回のときだけ加算） |
| ホームでサウンドを切り替えたとき | `soundOn` |
| ボス図鑑で「図鑑をリセット」を了承したとき | `bossKills` を空に、`perfectCount` を 0 にする |

- 更新は「読む → 変える → 全体を書き戻す」で行う。
- バトルの途中（1問ごと・1文字ごと）には保存しない。
- `lastBossId` の使い方は [ボスデータと選び方](../boss-zukan/01_ボスデータと選び方.md#ボスの選び方)、`recentIds` の使い方は [お題の選び方](../battle/05_お題の選び方.md) を参照。

## 読み込み

アプリは、ホームを開いたときと更新の直前に読み込む。

| 状態 | 動作 |
| --- | --- |
| キーが無い | 初期値で動かす。保存はまだしない |
| JSON として読めない | 全体を初期値で動かす。次の保存で上書きされる |
| `version` が現在（1）より大きい（このアプリより新しい版が書いたデータ） | 中身を読めないので使わず、初期値で動かす。**書き込みもしない**（書くと新しい版の記録を消してしまうため）。この間の記録は保存されない。帯は出さない |
| `version` が現在より小さい | 古い形から現在の形へ作り直す変換（`migrate`）をかけて使う。現在は version 1 しか無いので変換は未実装 |
| 項目の型が違う（例：`perfectCount` が文字列） | その項目だけ初期値に戻す。ほかの項目は使う |
| 配列の中身が文字列でない／負の回数など | 不正な要素だけ捨てる |
| 知らない項目がある | 無視する。次の保存で消える |

- 保存時は常に `version` を現在の値にして書く。
- localStorage の読み書き自体が失敗したときは [エラーと特殊表示](../common/02_エラーと特殊表示.md#保存できないとき) に従う。

### 作り替える前の形で保存されたデータ

作り替えの途中で、同じキーに前の形（`recentIds` が配列ではなく、今は無い項目もある）で保存された端末がありうる。`version` は同じ 1 のままとし、変換は作らない。上の表のとおりに読めば足りるため。

- `recentIds` は型が違うので、初期値（空）に戻る。
- 今は無い項目は、知らない項目として無視する。
- 撃破回数・パーフェクト回数・サウンド設定は、そのまま使う。
