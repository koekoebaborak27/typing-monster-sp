# 出題の選び方

出題APIが5問を選ぶ手順。要件は [難易度と出題](../../01_requirements/battle/03_難易度と出題.md)・[リベンジモード](../../01_requirements/revenge/01_リベンジモード.md)。実装は `quiz/selection.ts`（純粋関数）。

## 返す5問の意味

返す5問は**重複しない5問**で、並びは次のとおりとする。

| 位置 | 名前 | 使い方 |
| --- | --- | --- |
| 1〜3番目 | 通常問題 | この順に出す |
| 4〜5番目 | 予備問題 | とどめ問題に、間違えた問題が足りないときの穴埋めとして使う |

とどめ問題2問の決め方は、通常問題を答え終えたあとに端末が行う（出題APIは関与しない）。

| 通常問題の間違い（間違えた順に W1, W2, W3） | とどめ1問目 | とどめ2問目 |
| --- | --- | --- |
| 0問 | 予備1 | 予備2 |
| 1問 | W1 | 予備1 |
| 2問 | W1 | W2 |
| 3問 | W1 | W2（W3 は出さない。結果画面のふりかえりには出る） |

- 5問は通常・リベンジのどちらでも同じ形で返す。

## 通常モードの選び方

難易度 L（`level`）について、次の順で選ぶ。乱数は引数で受け取る。

1. **優先問題を決める。** `wrongIds` のうち、実在し、`level` が L のものを集める。1問以上あれば、その中から1問をランダムに選ぶ。無ければ優先問題なし。
2. **候補を作る。** `level` が L で、`recentIds` に含まれない問題を候補とする。優先問題は候補に関係なく選ぶ（「次回のバトルで出す」ため、最近出ていても優先する）。
3. **通常問題3問を選ぶ。** 3問はすべて異なる教科にする。
   1. 優先問題があれば、1問目の枠を取る。
   2. 残りの枠は、すでに選んだ教科を除いた教科から、教科をランダムに選び、その教科の候補からランダムに1問選ぶ。
   3. 3問が決まったら、並びをランダムに入れ替える。
4. **予備問題2問を選ぶ。** 選んだ3問を除いた候補から、教科を問わずランダムに2問選ぶ。
5. **候補が足りないとき**（教科の候補が0、または予備が2問に満たない）は、`recentIds` に含まれる問題も候補に加えて選び直す。教科の重複なしは守る。
   - 手順3で選ぶ教科は、候補が1問以上ある教科に限る。候補が0の教科があっても、まだ選んでいない教科で候補のあるものが残っていれば、そこから選び、選び直しはしない。選び直すのは、選べる教科が無くなって3問がそろわないときだけとする（最近出た問題をできるだけ避けるため）。

## リベンジモード

- `wrongIds` のうち実在するものを集め（これを `validIds` とする）、すべてをシャッフルして先頭5問を返す。1〜3番目が通常問題、4〜5番目が予備問題。
- `recentIds`・教科の重複なしは使わない。難易度は問わない。
- `validIds` が5問未満のときは 409 を返す（[APIの入出力](02_APIの入出力.md#409-の応答)）。

## 端末側の記録

出題APIの返事を受け取ったあとの端末側の処理。保存先と形は [保存データの形](../local-storage/01_保存データの形.md)。

| 場面 | 処理 |
| --- | --- |
| バトルの開始時（通常モード） | 返された5問のIDを、その難易度の「最近出た問題ID」の末尾へ加え、新しい20件だけ残す。リベンジモードでは加えない |
| 各問題への**最初の**解答 | 正解なら、その問題を「まちがえた問題」から外す。不正解なら加える（すでにあれば何もしない）。保存は答えた時点で行う |
| とどめ問題の**出し直し**の解答 | 「まちがえた問題」は変えない（最初の解答で決まっているため） |
| 返事の `unknownIds` | 「まちがえた問題」から外す |

## 先読み

結果画面を表示したときに、次のバトルの問題を取得して `BattleSession` に置く。

1. バトルの終了処理（記録の保存）がすべて終わってから行う。最新の「まちがえた問題」と「最近出た問題ID」を送るため。
2. 同じモード・難易度で出題APIを呼ぶ。リベンジモードで結果が「ぜんぶリベンジした！」のとき（まちがえた問題が5問未満）は呼ばない。
3. 「もう1回」をタップしたとき、先読みが済んでいればすぐバトルを始める。取得中なら「よみこみ中…」を出して待つ。失敗していれば取得し直す（[エラーと特殊表示](../common/02_エラーと特殊表示.md#一覧)）。
4. 先読みした問題は、そのバトルを始めるまで「最近出た問題ID」には加えない。「ホームへ」を選んだ場合は捨てる。
