# URLと画面遷移

全体の遷移図は [画面遷移図](../画面遷移図.md)。画面の内容は [要件定義書](../../01_requirements/common/01_概要と対象範囲.md) と [screens.html](../../mock/screens.html)。

## URL

| URL | 画面 | 備考 |
| --- | --- | --- |
| `/` | ホーム | |
| `/battle` | バトル | 開いた時点で、端末がボスと5語を選んで始める（通信しない） |
| `/result` | 結果 | バトル終了時にメモリへ置いた結果を表示する |
| `/zukan` | ボス図鑑 | |
| `/offline.html` | オフライン用の静的ページ | Service Worker だけが返す。詳細は [04_PWA詳細.md](04_PWA詳細.md) |

## 画面間で受け渡すもの

画面をまたいで使う値は、URLにも localStorage にも置かず、アプリ全体で共有するメモリ（`BattleSession`）に置くこと。

| 項目 | 内容 |
| --- | --- |
| `canStart` | バトルを始めてよいか。初期値は `false`。ホームの「バトル スタート」か、結果の「もう1回」を押したときに `true` にする |
| `result` | 結果画面に出す値（[結果の作り方](../battle/02_結果画面の表示.md#結果の作り方)）。初期値は `null`。バトルを始めるときに `null` に戻す |

- `BattleSession` は `app/layout.tsx` に置いた Client Component が持つ。画面を移動しても消えないが、再読み込みや画面を閉じると消える（途中で離れたバトルを破棄する要件と一致する）。
- `canStart` を持つのは、`/battle` を直接開いたときにバトルを始めないため。ボタンのタップを通らないと、音を有効にできず、キーボードも出せない。
- お題・ボス・打っている途中の内容は、バトル画面の中だけで持ち、`BattleSession` には置かない。

## 遷移

| 操作 | 遷移 | 履歴の扱い |
| --- | --- | --- |
| ホームで「バトル スタート」をタップ | `/battle` | 追加する（`push`） |
| ホームで「ボス図鑑」をタップ | `/zukan` | 追加する |
| ボス図鑑で「もどる」をタップ | `/` | 追加する |
| バトルでとどめの一撃の演出が終わる | `/result` | 置き換える（`replace`） |
| 結果で「もう1回」をタップ | `/battle` | 置き換える |
| 結果で「ホームへ」をタップ | `/` | 置き換える |
| バトル中に端末の戻る操作 | `/`。そのバトルは破棄する。確認画面は出さない | ブラウザの動作に従う |

結果から戻る操作をしてもバトルには戻らず、ホームへ行く（`replace` のため）。

## 直接開いたとき・再読み込み

| 開いた URL | 状態 | 動作 |
| --- | --- | --- |
| `/battle` | `BattleSession` の `canStart` が `false` | `/` へ置き換える（`replace`） |
| `/result` | `BattleSession` に結果が無い | `/` へ置き換える |
| `/` `/zukan` | | そのまま表示する |

バトル中に再読み込みすると、そのバトルは破棄される。開始時に保存した記録（直前のボス・最近出た言葉）は残る（[保存データの形](../local-storage/01_保存データの形.md#保存のタイミング)）。
