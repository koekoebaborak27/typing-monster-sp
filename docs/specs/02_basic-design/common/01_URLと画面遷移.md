# URLと画面遷移

全体の遷移図は [画面遷移図](../画面遷移図.md)。画面の内容は [要件定義書](../../01_requirements/common/01_概要と対象範囲.md) と [screens.html](../../mock/screens.html)。

## URL

| URL | 画面 | 備考 |
| --- | --- | --- |
| `/` | ホーム | |
| `/battle` | バトル | 開始時に出題APIを呼ぶ。開始に必要な情報（モード・難易度）はメモリから受け取る |
| `/result` | 結果 | バトル終了時にメモリへ置いた結果を表示する |
| `/zukan` | ボス図鑑 | |
| `/offline.html` | オフライン用の静的ページ | Service Worker だけが返す。詳細は [04_PWA詳細.md](04_PWA詳細.md) |

## 画面間で受け渡すもの

バトルの内容（モード・難易度・出題された問題・ボス・結果）は、URLにも localStorage にも置かず、アプリ全体で共有するメモリ（`BattleSession`）に置くこと。

- `BattleSession` は `app/layout.tsx` に置いた Client Component が持つ。画面を移動しても消えないが、再読み込みや画面を閉じると消える（途中で離れたバトルを破棄する要件と一致する）。
- 結果画面を表示したときに、同じモード・難易度の次のバトルの問題を出題APIから先に取得し、`BattleSession` に置く（取得の手順は [出題の選び方](../question-api/01_出題の選び方.md#先読み)）。

## 遷移

| 操作 | 遷移 | 履歴の扱い |
| --- | --- | --- |
| ホームで難易度ボタン／リベンジをタップ | `/battle` | 追加する（`push`） |
| ホームで「ボス図鑑」をタップ | `/zukan` | 追加する |
| ボス図鑑で「もどる」をタップ | `/` | 追加する |
| バトルでとどめの一撃の演出が終わる | `/result` | 置き換える（`replace`） |
| 結果で「もう1回」をタップ | `/battle`（同じモード・難易度） | 置き換える |
| 結果で「ホームへ」をタップ | `/` | 置き換える |
| バトル中に端末の戻る操作 | `/`。そのバトルは破棄する。確認画面は出さない | ブラウザの動作に従う |

結果から戻る操作をしてもバトルには戻らず、ホームへ行く（`replace` のため）。

## 直接開いたとき・再読み込み

| 開いた URL | 状態 | 動作 |
| --- | --- | --- |
| `/battle` | `BattleSession` に開始情報が無い | `/` へ置き換える（`replace`） |
| `/result` | `BattleSession` に結果が無い | `/` へ置き換える |
| `/` `/zukan` | | そのまま表示する |

バトル中に再読み込みしても、すでに答えた問題の記録は保存済みなので消えない（[保存データの形](../local-storage/01_保存データの形.md#保存のタイミング)）。
