# エラーと特殊表示

表示する文言はそのまま画面に出す文字列。小学4〜6年生が読むため、ひらがな中心にする。

## 一覧

| 場面 | 条件 | 表示する文言 | ボタン |
| --- | --- | --- | --- |
| 問題の取得中 | `/battle` 表示直後〜出題APIの応答まで | よみこみ中… | なし |
| オフライン | 出題APIの呼び出しに失敗し、`navigator.onLine` が `false` | インターネットにつないでね | 「もういちど」「ホームへ」 |
| 問題の取得に失敗 | 出題APIの呼び出しに失敗し、オンラインと判断される（通信エラー・5xx） | もんだいをよみこめなかったよ。もういちどためしてね。 | 「もういちど」「ホームへ」 |
| リベンジできない | 出題APIが 409（`REVENGE_NOT_AVAILABLE`）を返した | リベンジできるもんだいがなくなったよ | 「ホームへ」 |
| 出題APIの 400 | 応答が 400（通常は起こらない。実装ミスの検知用） | 問題の取得に失敗と同じ文言 | 同上 |
| 保存できない | localStorage が使えない（プライベートモード等で読み書きに失敗） | きろくをほぞんできないよ。あそぶことはできるよ。 | なし（ホームの上部に帯で表示） |

- 「もういちど」は同じ条件で出題APIをもう一度呼ぶ。「ホームへ」は `/` へ移る。
- 出題APIが 409 を返したときは、応答に含まれる `unknownIds` を「まちがえた問題」から消してからホームへ戻る（[APIの入出力](../question-api/02_APIの入出力.md#409-の応答)）。
- 結果画面の先読みが失敗しても、結果画面には何も表示しない。「もう1回」をタップした時点で、上の表に従って取得し直す。

## 保存できないとき

- 読み書きに失敗した場合は、メモリ上の保存データだけで動かす。ページを開いている間は記録が残るが、閉じると消える。
- 判定は、ホームを開いたときに一度だけ行う。その後に書き込みが失敗した場合も、同じ扱いにして帯を出す。

## オフライン用の静的ページ

Service Worker が、ページの取得に失敗したときだけ返す。内容は次のとおり。

- 見出し: クイズモンスター
- 本文: インターネットにつないでね
- ボタン: 「もういちど」（再読み込み）
