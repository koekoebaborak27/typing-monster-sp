## ボスの選び方

- バトルを始めるときに、端末が選ぶ。
- 直前のバトルのボス以外の19体から、等しい確率でランダムに1体を選ぶ。
- 「直前のボス」は、保存データの `lastBossId` を使う。ボスを選んだらすぐ `lastBossId` を更新して保存する（途中で離れたバトルのボスも直前として数える）。保存は、[最近出た言葉の記録](../battle/05_お題の選び方.md#最近出た言葉の記録) と一緒に1回で行う。
- `lastBossId` が `null`（初回、またはボスの一覧に無いID）のときは、20体から選ぶ。
- 「もう1回」でも毎回選び直す。

## 枠ランクの判定

`rank.ts` で、撃破回数 `n` から次のとおり決める。

| `n` | ランク |
| --- | --- |
| 0 | なし（シルエット表示） |
| 1〜2 | 銅 |
| 3〜4 | 銀 |
| 5以上 | 金 |

結果画面の表示は、撃破回数を増やす前を `before`、増やした後を `after`（`before + 1`）として決める。

| 条件 | 表示 |
| --- | --- |
| `before` が 0 | NEW！ボス図鑑に登録された！ |
| `before` のランク ≠ `after` のランク（`before` が 0 の場合を除く） | ランクアップ！ 枠が銀になった（金になったときは「枠が金になった」） |
| 上のどちらでもない | 表示しない |

## ボス図鑑の画面

- 並び: 撃破済みを先頭にし、同じグループの中は [ボス一覧](#ボス一覧) の順にする。
- 4列のマスで20体を表示する（[screens.html](../../mock/screens.html)）。
- 収集率は「撃破済みのボスの数 / 20」（例：`7 / 20`）。
- 収集率の下に「パーフェクト勝利 N回」と小さく出す（N は保存データの `perfectCount`。ミス0回で勝った回数）。
- 「図鑑をリセット」を押したら、確認（「図鑑を空にします。本当によろしいですか？」）を出し、了承されたら `bossKills` を空に、`perfectCount` を 0 にして保存する（[要件](../../01_requirements/boss-zukan/01_ボス図鑑.md#図鑑のリセット)）。`lastBossId`・`recentIds`・`soundOn` は変えない。
- 保存データに、一覧に無いボスIDがあっても無視する（表示にも収集率にも数えない）。
