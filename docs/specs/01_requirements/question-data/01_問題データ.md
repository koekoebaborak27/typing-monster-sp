# 問題データ

## 保存場所と読み込み

- 問題データは `src/modules/quiz/data/questions.json` の1ファイルに置くこと。
- 読み込むのは `repository.ts` だけとすること。
- `public/` には置かないこと（正解をURLで取れないようにするため）。

## データの形

| 項目 | 内容 |
| --- | --- |
| id | 問題ID。`l{level}-{genre}-{2桁の番号}` の形（例：`l1-math-03`）。一度付けたら変えないこと（端末に保存されるため） |
| genre | `japanese`（国語）／`math`（算数）／`science`（理科）／`social`（社会）／`logic`（ひらめき） |
| grade | 4／5／6。level と1対1で対応する |
| level | 1〜3（かんたん／ふつう／むずかしい） |
| question | 問題文 |
| choices | 選択肢3つ。`{ id: "c1" \| "c2" \| "c3", text }` の形 |
| answer | 正解の選択肢ID |
| explanation | 解説。30〜45字 |

- 選択肢IDに a / b / c は使わないこと（画面のラベル A / B / C と混同しないため）。
- とどめ問題で選択肢を並べ替えるため、答え合わせは選択肢の位置ではなく、選択肢ID（`answer`）で判定すること。
- 解説は、正解の理由とひっかけポイントを1文で書くこと。

## 問題数

- 作成済みの問題数は、3難易度 × 5教科 × 16問 ＝ 240問（1難易度80問）である。

## 問題作成のルール

問題データは `src/modules/quiz/data/questions.json` に作成済みである。作成済みの問題は次のルールに従っている。問題を追加・修正するときも同じルールを守ること。

- 図や表を使わず、文字だけで解けること。
- ふざけた選択肢は入れないこと。
- 二重否定の問いは使わないこと。
- 年によって変わる事実は使わないこと。
- 社会は学年で範囲が異なること：4年生は都道府県・くらしを支える仕事、5年生は国土・産業、6年生は歴史・政治など。

## 表記のルール

作成済みの問題は次の表記に従っている。問題を追加・修正するときも同じ表記を守ること。

- 漢字はその学年までに習うものだけを使い、ふりがなは付けないこと。
- ただし固有名詞（例：富士山、源頼朝）と教科書の用語（例：沸騰、三権分立）は、習っていない漢字でも漢字で書くこと。
- 国語の読み問題では、答えの漢字が分かってしまわないようにすること。
- 文字数の目安は、問題文60字以内、選択肢15字以内とすること（スマホの1画面に収めるため）。
