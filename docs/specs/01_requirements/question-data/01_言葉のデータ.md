# 言葉のデータ

バトルのお題にする言葉の一覧。

## 中身

- 言葉は約100語とすること。
- ひらがなだけで書くこと。漢字・カタカナ・英字・数字は使わない。のばす音「ー」は使ってよい（ふつうはカタカナで書く言葉を、ひらがなで書いて入れてよい。例: らーめん）。
- 分類（ジャンル）と難易度は付けないこと。
- 言葉ごとに、変わらないIDを持つこと。一度付けたIDは変えない（最近出た言葉として端末に保存されるため）。

## 保存場所

- 画面側（端末で動くプログラムの中）に持つこと。サーバーから取得しない。
- 隠すデータではないので、端末から中身が見えてよい。

## 作り方

- あらかじめ作ったデータとして静的に管理し、中身はオーナーが確かめること。
