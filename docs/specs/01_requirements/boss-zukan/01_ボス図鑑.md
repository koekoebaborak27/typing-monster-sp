# ボス図鑑

問題図鑑は作らず、ボス図鑑だけにすること。ボスの一覧は [ボス](../battle/04_ボス.md)。

## 表示内容

- 1体ごとに表示するのは**絵文字・名前・撃破回数のみ**とすること。見やすさを優先する。
- 収集率を「7 / 20」の形で表示すること。

## 未撃破のボス

- 黒いシルエットで表示すること（CSS の `filter: brightness(0)`）。
- 名前は「？？？」と表示すること。

## 枠の色

撃破回数で枠の色が変わること。

| 撃破回数 | 枠の色 |
| --- | --- |
| 1回 | 銅 |
| 3回 | 銀 |
| 5回 | 金 |

## 結果画面での表示

- 初めて倒したとき「NEW！ボス図鑑に登録された！」と表示すること。
- 枠の色が上がったとき「ランクアップ！」と表示すること。
