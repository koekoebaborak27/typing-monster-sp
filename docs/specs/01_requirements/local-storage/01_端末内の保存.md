# 端末内の保存

保存先は localStorage のみとすること。サーバーやDBには保存しない。

## 保存する項目

| 項目 | 用途 |
| --- | --- |
| 最近出た言葉のID | 同じ言葉を続けて出さないため。直近20語（4バトル分）。難易度が無いので1本だけ持つ |
| 直前のバトルのボスID | 直前と同じボスを出さないため。再読み込みや閉じたあとも守る |
| ボスごとの撃破回数 | ボス図鑑用 |
| パーフェクト勝利の回数 | 記録として表示する |
| サウンドON/OFF | ホームでの設定の保持 |
| 保存データのバージョン番号 | あとで保存の形を変えたとき、古い形のデータを新しい形に作り直して記録を消さないため |

## 保存しないもの

- ミスした言葉・ミスの回数は保存しないこと（優先して出す仕組みもリベンジモードも無いため）。
- 打つ速さ・最高評価は保存しないこと。

## 記録の消去

- 消せるのは、ボス図鑑のリセット（[ボス図鑑](../boss-zukan/01_ボス図鑑.md#図鑑のリセット)）で消える記録だけとすること。
- それ以外の記録を消す機能は作らないこと。
