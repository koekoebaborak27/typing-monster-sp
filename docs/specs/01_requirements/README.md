# 01_requirements/ — 要件定義書

機能ごとにディレクトリを作り、その中に要件定義書を置く。

```
01_requirements/
└─ <機能名>/
   └─ 01_<機能名>.md
```

書くこと: 誰が・何のために使うか、対象範囲、機能一覧、権限、非機能要件（性能・セキュリティ・可用性）、対象外とすること。

書かないこと: 画面項目やテーブル定義（基本設計へ）、検討の経緯（`docs/todo/history/` へ）。
