# バトルのルール

画面の配置と見た目は [screens.html](../../mock/screens.html) と [DESIGN.md](../../../../DESIGN.md) に従うこと。

## 基本

- 1バトルは5問とし、通常問題3問＋とどめ問題2問とすること。1問は、お題の言葉1つを打ち終えることを指す。
- 制限時間・タイマーはなし。打つ速さも記録しないこと。
- ボスのHPは500とすること。
- ライフ・失敗・ゲームオーバーは無い。お題を打ち終えれば必ず次へ進み、5問を打ち終えれば必ずボスを倒せること。

## お題と入力

- お題は、ひらがなの言葉をそのまま表示すること。打てた文字と、次に打つ文字が見分けられるようにする。
- 入力はスマホ標準のキーボード（フリック入力）で行うこと。画面内に自前のキーは並べない。
- 入力欄は見えるようにし、打った文字をそのまま出すこと。
- 判定は1文字ごとに行うこと。言葉を打ち終えてからまとめて判定する作りにはしない。
- お題のまわりに説明文は置かないこと（キーボードが出たままで全部を見せるため）。
- 予測変換や自動の直しは、できる範囲で抑えること。それでも候補を選ばれた場合は、入った文字をそのままお題と比べる。

## ミス

- お題の次の文字と違う文字が入ったら、ミス1回とすること。
- 間違えた文字は取り消さないこと。赤い字で入力欄に残し、打った人が消すキーで消してから打ち直す（何を間違えたかを分かりやすくするため）。
- ミスしたことは、色だけでなく文でも知らせること（例：「「け」は ちがうよ。⌫ で けしてね」）。
- 消している間は、ミスを数えないこと。
- ミスは1バトルの通算で数え、バトル中は画面に「ミス 0回」のように出すこと。
- ミスをしても、HP・ダメージ・問題数には影響しないこと。影響するのは、怒りモードと結果の評価だけとする。

## 途中の形

ある文字を打つ途中で、入力欄に一時的に出る別の文字は、ミスにしないこと。

| 打つ文字の例 | ミスにしない途中の形 |
| --- | --- |
| が | か |
| っ | つ |
| ぱ | は・ば |
| パソコンのローマ字入力 | ひらがなになる前の英字（例：「か」を打つ途中の「k」） |

- 途中の形のまま次の文字を打ったら、ミスとすること。
- 同じキーを連打して文字を送る打ち方（か→き→く）は、途中の形として扱わず、ミスに数えること。
- パソコンのローマ字の打ち間違いは、ひらがなになった時点でお題と違っていればミスとすること。

## ダメージ

| 問題 | ダメージ |
| --- | --- |
| 通常問題（1〜3問目） | 1問につき100 |
| とどめ問題の1問目（4問目） | 残りHPの半分 |
| とどめ問題の2問目（5問目） | 残りHPすべて |

- 失敗が無いので、HPは必ず 500 → 400 → 300 → 200 → 100 → 0 と減ること。
- 言葉を打ち終えたら、「100ダメージ！」のように、数字に「ダメージ！」を付けて表示し、入力欄を空にして次のお題へ進むこと。
- 5問目は「とどめの一撃！」として表示し、HPを0にしてから結果画面へ進むこと。打ち終えたあとは、それ以上打てないようにする。
- とどめ問題の間は、とどめ問題であることと何問目か（「とどめ問題 1/2」）を表示すること。

## 怒りモード（いかり）

ミスが通算5回に達したら、ボスが「怒りモード」になること。そのバトルの最後まで続ける。

- 背景が赤くなる
- ボスが小刻みに震え続ける
- 💢マークを表示する
- 吹き出しで「もうゆるさないぞ！」と表示する
- ボスの名前が「いかりの◯◯」に変わる

HPは戻さないこと（見た目だけを変える）。CSSと文字の差し替えのみで実装すること。

## サウンド

- 言葉を打ち終えたときの音と、ミスを数えたときの音の2種類を鳴らすこと。
- Web Audio APIで音をコード生成すること（音声ファイルは使わない）。
- ブラウザはタップ前に音を鳴らすことを禁止しているため、最初のタップ（「バトル スタート」）で音を有効化すること。
- ホームでON/OFFを切り替えられること。

## 途中で離れた場合

- 再読み込み・画面を閉じた場合、そのバトルは破棄すること（続きからは遊べない）。
