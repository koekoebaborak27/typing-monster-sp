# 結果の評価

## 評価の基準

そのバトルのミスの回数（通算）で決めること。ミスの数え方は [バトルのルール](01_バトルのルール.md#ミス)。

| ミスの回数 | 評価 | 表示 |
| --- | --- | --- |
| 0回 | ★3 | パーフェクト勝利！ |
| 1〜2回 | ★2 | 勝利！ |
| 3〜4回 | ★1 | 勝利！ |
| 5回以上（怒りモード） | ★なし | ギリギリ勝利！ |

- 何問目でミスしたかは、評価に影響しないこと。
- HPの減り方は、評価に関係なく毎回同じであること（[ダメージ](01_バトルのルール.md#ダメージ)）。

## 結果画面

- 勝利の種類と★、倒したボスと撃破回数（「◯◯をたおした（3回目）」）を表示すること。
- ミスの回数を大きく表示すること。その下の一言は「ミス 0回で ★3つ！」とし、★3のときは「パーフェクト！」に変える。
- ふりかえり（間違えた内容の一覧）は出さないこと。
- ボタンは「もう1回」「ホームへ」の2つとすること。
- ボス図鑑に関する表示は [ボス図鑑](../boss-zukan/01_ボス図鑑.md#結果画面での表示) に従うこと。

## 記録するもの

- 最高評価は記録しないこと（すぐ上限に達して変化がなくなるため）。
- 代わりに、遊ぶほど増える記録として「ボスごとの撃破回数」と「パーフェクト勝利の回数」を保存すること。パーフェクト勝利は、ミス0回で勝ったバトルを指す。
