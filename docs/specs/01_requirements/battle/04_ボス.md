# ボス

## 種類

- ボスは20種類とすること。

| | | | | |
| --- | --- | --- | --- | --- |
| 🐙レンダダコ | 👹ミスタッチオニ | 🐉キーボードラゴン | 👻クウハクゴースト | 🦊ヘンカンギツネ |
| 🐍ナガブンヘビ | 🦇サカサマコウモリ | 🐸ウチマチガエル | 🦉メカクシフクロウ | 🐻ドウジオシグマ |
| 🕷️カラマリグモ | 🦖タイピングザウルス | 🤖セイカクロボ | 🧟ノロユビゾンビ | 🦂ヒトサシサソリ |
| 🦈ハヤウチザメ | 🦍バンバンゴリラ | 🐌イチモジマイマイ | 👾キーインベーダー | 🐊デリートワニ |

## 出現ルール

- 毎回ランダムに選ぶこと。
- 直前と同じボスは出さないこと。
- ボス名は固有名とし（例：ミスタッチオニ）、[怒りモード](01_バトルのルール.md#怒りモードいかり) では「いかりの◯◯」と表示すること。
