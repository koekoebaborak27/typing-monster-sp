# ボス

## 種類

- ボスは20種類とすること。

| | | | | |
| --- | --- | --- | --- | --- |
| 🐙ウッカリダコ | 👹ヒッカケオニ | 🐉ナゾトキドラゴン | 👻ワスレゴースト | 🦊ダマシギツネ |
| 🐍ヘリクツヘビ | 🦇カンチガイコウモリ | 🐸ケタマチガエル | 🦉シッタカフクロウ | 🐻ネボスケグマ |
| 🕷️ヨミトバシグモ | 🦖マルアンキザウルス | 🤖ヤマカンロボ | 🧟ナマケゾンビ | 🦂ウロオボエサソリ |
| 🦈アワテザメ | 🦍ゴリオシゴリラ | 🐌アトマワシマイマイ | 👾ハテナインベーダー | 🐊イイワケワニ |

## 出現ルール

- 毎回ランダムに選ぶこと。
- 直前と同じボスは出さないこと。
- ボス名は固有名とし（例：ヒッカケオニ）、[怒りモード](01_バトルのルール.md#怒りモードいかり) では「いかりの◯◯」と表示すること。
