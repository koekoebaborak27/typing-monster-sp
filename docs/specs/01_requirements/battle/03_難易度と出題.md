# 難易度と出題

## 難易度

| 難易度 | 内容 |
| --- | --- |
| かんたん | 4年生の内容 |
| ふつう | 5年生の内容 |
| むずかしい | 6年生の内容＋ひっかけ・ひらめき問題 |

- 問題データの `level` 1／2／3 が、かんたん／ふつう／むずかしい にそのまま対応すること。
- `grade` は level と1対1（level 1＝4年、2＝5年、3＝6年）とし、使ってよい漢字と内容の範囲を決めるために持つこと。

## 出題の組み立て

- ジャンル選択はなし。出題は常にミックスとすること。
- 通常問題3問はすべて異なる教科から出すこと。とどめ問題は教科が重なってよい。
- 次回以降のバトルでは、選んだ難易度で間違えた問題を1問優先して混ぜ、正解したら優先リストから外すこと。
- ほかの難易度で間違えた問題は、リベンジモードで出すこと。詳細は [リベンジモード](../revenge/01_リベンジモード.md)。
- 最近出た問題は再出題しないこと。詳細は [端末内の保存](../local-storage/01_端末内の保存.md)。
