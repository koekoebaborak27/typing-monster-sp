# PWA

## 要件

- ホーム画面に追加でき、全画面で開けること。
- インターネット接続がある前提とし、オフラインでは遊べないこと。オフライン時は「インターネットにつないでね」と表示する。
- アプリ名・短い名前は「クイズモンスター」とし、画面の向きは縦に固定すること。
- Next.js 標準の manifest と、画面の部品をためておく最小限の Service Worker で作ること。追加のライブラリは使わない。

## アイコン画像

- アイコン画像はオーナーが用意すること。
- PNG で 192×192 と 512×512 の2種類とする。
- 512×512 は Android が丸や角丸に切り抜くため、絵柄を中央の約8割に収めること。
