# 技術と運用

## 技術スタックと制約

- TypeScript + Next.js（App Router）で作ること。
- Vercel（Hobbyプラン・無料）にデプロイすること。
- AI API・有料APIは使わないこと。DBも使わないこと。
- サーバー側の処理（出題API）は持たないこと。お題は画面側に持ち、判定もすべて端末内で行う。タイピングには、先に端末へ渡してはいけない正解が無いため。

## 言葉のデータの作り方

- お題にする言葉は、あらかじめ作ったデータとして静的に管理すること。詳細は [言葉のデータ](../question-data/01_言葉のデータ.md)。
- 中身はオーナーが確かめること。
