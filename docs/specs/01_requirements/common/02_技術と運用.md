# 技術と運用

## 技術スタックと制約

- TypeScript + Next.js（App Router）で作ること。
- Vercel（Hobbyプラン・無料）にデプロイすること。
- AI API・有料APIは使わないこと。DBも使わないこと。
- 学習目的もあるため、サーバー処理（Route Handlers）を含めること。そのため静的書き出し（`output: 'export'`）は使わないこと。

## 問題データの作り方

- 問題データは `questions.json` で静的に管理し、AIで事前生成すること。詳細は [問題データ](../question-data/01_問題データ.md)。
- 品質チェックはオーナーがピックアップで行うこと（後日）。
