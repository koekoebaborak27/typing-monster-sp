# 概要と対象範囲

## 目的・対象ユーザー

- ひらがなの言葉をキーボードで打ってモンスターを倒す、ボスバトル型のタイピングゲームとすること。
- 対象は小学校高学年とし、スマホで使うWebアプリとすること。
- 入力にはスマホ標準のキーボード（フリック入力）を使うこと。ふだんの入力の練習になるようにする。
- 問題を間違えるという考えは持たないこと。誰でも最後はボスを倒せ、上手さはミスの回数による勝ち方の評価で差がつくこと。

## 画面一覧（4画面）

配置と見た目は [screens.html](../../mock/screens.html) と [DESIGN.md](../../../../DESIGN.md) に従うこと。

| 画面 | 内容 |
| --- | --- |
| ホーム | タイトル、「バトル スタート」、サウンドON/OFF、ボス図鑑への入口（収集率付き） |
| バトル | ボス（絵文字）、HPバー、何問目か、ミスの回数、お題、入力欄 |
| 結果 | 勝利の種類と★、ミスの回数、「もう1回」「ホームへ」ボタン |
| ボス図鑑 | 20体のボスの一覧と撃破回数、パーフェクト勝利の回数、図鑑のリセット |

## 個人情報

- 名前などの個人情報の入力欄は作らないこと。

## 作らないもの

- 難易度の選択
- 言葉の分類（ジャンル）の選択
- 制限時間・タイマー、打つ速さの記録
- ライフ、問題の失敗、ゲームオーバー
- コンボの表示
- リベンジモード（復習モード）
- ミスした言葉の記録と、その言葉を優先して出す仕組み
- 結果画面のふりかえり
- 出題API（サーバー側の処理）
- ランキング
- デイリー問題
- 称号
- 言葉の図鑑
- アクセス解析
