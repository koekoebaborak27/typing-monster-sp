# 概要と対象範囲

## 目的・対象ユーザー

- 3択クイズに答えてモンスターを倒す、ボスバトル型の学習ゲームとすること。
- 対象は小学4〜6年生とし、スマホで使うWebアプリとすること。
- 1バトルは約1分で終わること。基本的には誰でも最後はボスを倒せ、上手さは勝ち方の評価で差がつくこと。
- 間違えた問題は、その場の解説と、バトル最後の「とどめ問題」での出し直しで覚えさせること。

## 画面一覧（4画面）

| 画面 | 内容 |
| --- | --- |
| ホーム | タイトル、難易度選択（かんたん／ふつう／むずかしい）、リベンジモード（未開放時は鍵マーク）、サウンドON/OFF、ボス図鑑への入口 |
| バトル | ボス（絵文字）、HPバー、ライフ（ハート3つ）、3択の問題、コンボ表示 |
| 結果 | 勝利の種類と★、今回まちがえた問題のふりかえり（正解と解説）、「もう1回」ボタン |
| ボス図鑑 | 20体のボスの一覧と撃破回数 |
