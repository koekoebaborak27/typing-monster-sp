# 非機能要件

## 動作環境

- 対象は Android の Chrome（最新版）、スマホ縦画面とすること。iPhone は対応しない。
- パソコンで開いた場合は、スマホの幅で中央に表示すること。

## 性能（速さ）

- 解答中は通信しないこと。タップした瞬間に正誤を表示する。
- 結果画面を表示している間に、次のバトルの問題を先に取得しておくこと。「もう1回」ですぐ始められるようにする。
- 出題APIは、起動時にメモリへ読み込んだ問題データから選ぶだけにすること（毎回ファイルを読み直さない）。

## セキュリティ

- 答え合わせは端末内で行うため、正解データが端末に渡ることを許容する。ランキング等の競う要素がなく、ズルをしても誰も困らないため。
- 問題データは `public/` に置かないこと（正解をURLで直接取れないようにするため）。

## 可用性

- インターネット接続がある前提とし、オフラインでは遊べないこと。詳細は [04_PWA.md](04_PWA.md)。
