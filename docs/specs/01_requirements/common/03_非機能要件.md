# 非機能要件

## 動作環境

- 対象は Android の Chrome（最新版）、スマホ縦画面とすること。iPhone は対応しない（確認もしない）。
- パソコンでも遊べること。日本語入力をオンにしたローマ字入力で打つ。日本語入力がオフのままでは進めないので、その場合は「にほんご入力を オンにしてね」と知らせること。
- パソコンで開いた場合は、スマホの幅で中央に表示すること。

## 画面の収まり

- バトル画面は、キーボードが出たままの状態で、ボス・HP・お題・入力欄がすべて見えること。
- バトル画面を開いたら、タップしなくてもすぐ打てること（入力欄を選んだ状態にし、キーボードを出したままにする）。

## 性能（速さ）

- バトル中は通信しないこと。打った瞬間に判定し、結果を表示する。
- 「もう1回」「バトル スタート」を押したら、待たずにバトルを始められること（お題は画面側に持つため、取得の待ち時間が無い）。

## セキュリティ

- お題と判定はすべて端末内にあり、隠すデータは無い。ランキング等の競う要素がなく、ズルをしても誰も困らないため、記録の書き換えへの対策はしないこと。

## 可用性

- インターネット接続がある前提とし、オフラインでは遊べないこと。詳細は [04_PWA.md](04_PWA.md)。
