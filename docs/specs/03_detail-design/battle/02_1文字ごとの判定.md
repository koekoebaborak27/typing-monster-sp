# 1文字ごとの判定

「合っている」「違っている」の分け方は [ミスの数え方](../../02_basic-design/battle/01_バトル画面の状態遷移.md#ミスの数え方) で決めている。ここでは、それを判定する関数 `judgeInput`（`battle/judge.ts`）の作りを決める。試作ページの `trial/judge.ts` を移して使う。

## 方針

- **入力欄の中身の全体を、お題と先頭から比べる。** 打った1文字だけを受け取る作りにはしない。スマホのキーボードは、変換中の文字を何度も書き換えて届けるので、「いま入力欄に何が入っているか」だけを見るのが確実なため。
- 画面にも状態にも触れない関数にする。ミスを数えるかどうかは決めない（それは `battle-reducer.ts` が、直前の状態と合わせて決める）。

## 引数と戻り値

`judgeInput(target, value)`。`target` はお題の文字列、`value` は入力欄の中身の全体。

| 戻り値の項目 | 型 | 内容 |
| --- | --- | --- |
| `confirmed` | `number` | お題の先頭から、正しく打てている文字数 |
| `pending` | `string` | 打っている途中の形（「が」を打つ途中の「か」、ローマ字入力の「k」など）。無ければ空 |
| `missed` | `boolean` | 「違っている」なら `true` |
| `tooManyLetters` | `boolean` | 末尾の英字が5文字以上なら `true`（「にほんご入力を オンにしてね」を出すため）。試作には無いので足す |

## 途中の形の表

濁点・半濁点・小さい文字のキーを押すたびに文字が切り替わる順番を、文字の並びで持つ。**目当ての文字より前にある文字**を、途中の形とする。

| 並び | 例 |
| --- | --- |
| あぁ・いぃ・うぅゔ・えぇ・おぉ | 「ぁ」を打つ途中の「あ」 |
| かが・きぎ・くぐ・けげ・こご | 「が」を打つ途中の「か」 |
| さざ・しじ・すず・せぜ・そぞ | |
| ただ・ちぢ・つっづ・てで・とど | 「っ」を打つ途中の「つ」、「づ」を打つ途中の「つ」「っ」 |
| はばぱ・ひびぴ・ふぶぷ・へべぺ・ほぼぽ | 「ぱ」を打つ途中の「は」「ば」 |
| やゃ・ゆゅ・よょ・わゎ | 「ょ」を打つ途中の「よ」 |

- 目当てが「は」のとき、「ば」「ぱ」は途中の形ではない（並びの後ろにあるため）。
- 同じキーを連打して文字を送る打ち方（か→き→く）は、並びが別なので途中の形にならない。

## 判定の手順

1. **末尾の英字を分ける。** `value` の末尾に英字（半角・全角）が続いていれば、その部分を取り分ける。
2. **英字より前の部分を、お題と先頭から1文字ずつ比べる。**
   - お題と同じ文字なら次へ進む。
   - 違う文字が**最後の1文字**で、お題のその位置の文字の途中の形なら、そこまでを `confirmed`、その文字を `pending` として「合っている」。
   - それ以外（違う文字、途中の形のまま次の文字がある、お題より長い）は、違う文字の位置を `confirmed` として「違っている」。
3. **英字があるとき**は、次をすべて満たす場合だけ、英字を `pending` として「合っている」にする。満たさなければ「違っている」。
   - 手順2の結果が「合っている」で、途中の形が無い
   - お題をまだ打ち終えていない
   - 英字が4文字以下（ローマ字のいちばん長い打ち方が4文字のため）
4. 英字が5文字以上のときは、`tooManyLetters` を `true` にする。

- ローマ字の打ち間違い（「か」のところで「s」）は、英字の間は判定しない。ひらがなになった時点でお題と違っていれば「違っている」になる。

## 単体テストで確かめること

試作のテスト（`trial/judge.test.ts`）を移して、次を確かめる（移した先は `battle/next/judge.test.ts`）。

| 分類 | 例（お題 →入力欄の中身） |
| --- | --- |
| お題どおり | 「がっこう」→「がっ」は `confirmed` 2 |
| 途中の形 | 「がっこう」→「か」「がつ」は `missed` が `false` |
| 途中の形のまま次を打つ | 「がっこう」→「かっ」は `missed` |
| 並びの後ろの文字 | 「はな」→「ば」は `missed` |
| 違う文字 | 「がっこう」→「がっけ」は `confirmed` 2 で `missed` |
| 違う文字のあとも続けて打つ | 「がっこう」→「がっけう」は `confirmed` 2 で `missed` |
| お題より長い | 「いぬ」→「いぬあ」は `missed` |
| ローマ字の途中 | 「さくら」→「s」「さk」「さくr」は `missed` が `false` |
| 英字が長すぎる | 「さくら」→「sakur」は `missed` で `tooManyLetters` |
| 打ち終えたあとの英字 | 「いぬ」→「いぬk」は `missed` |
| 全角の英字 | 「さくら」→「ｓ」は `missed` が `false` |
