# docs/development/ — 開発手順

| ファイル | 何が書いてあるか |
|---|---|
| [`本テンプレートPJをコピーする方法.md`](本テンプレートPJをコピーする方法.md) | このテンプレートから新しいプロジェクトのリポジトリを作る手順（通常は GitHub の「テンプレートリポジトリ」機能を使う方法A。使えない場合の完全手動の方法Bも併記） |
| [`gitの操作ルール.md`](gitの操作ルール.md) | 変更を Git に反映する手順（ブランチ → PR → CI → マージ → 後片付け）と、ドキュメントだけの変更で CI を止める方法 |

**ここに足すとよいもの**（プロジェクトで必要になった時点で作る）:

- プロジェクトの導入手順（初めて触る人向け。前提ソフト・`.env` の作り方・起動確認）
- プロジェクト実行手順（毎日の起動・終了）
- デバッグ手順（IDE のデバッグ構成の使い方）
- 本番リリース手順（全体の流れ。個々の手順は `docs/specs/99_infra/` へ）
- DB 定義を変更したい場合の流れ
